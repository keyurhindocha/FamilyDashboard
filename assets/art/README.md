# Background artwork

The board loads these four files from here (via the jsDelivr CDN, see `ASSET_BASE` in the board page):

| File | Used for |
|---|---|
| `parchment.png` | texture behind the cream panels |
| `day-background.png` | behind the daytime board (darkened) |
| `night-sky.png` | night mode |
| `corner.svg` | gold corner flourish on the week panel |

If a file is missing the board still works, with plain colours instead. See [docs/design.md](../../docs/design.md) to make your own.
